# Vendig Machine Store

Aplicação única para a loja e a gestão do negócio. O dashboard inclui gestão de inventário, compras, vendas, despesas, categorias e importação de livros.

## Fonte principal

- GitHub: `Catering1/vertice-unificado`, branch `main`.
- Supabase: projeto `mjtqdeesfapqfmxkhaby` (dados operacionais existentes).
- Dashboard: `/admin`.
- Loja pública: `/`.

Fazer alterações no projeto Lovable ligado a este repositório e manter as migrações de base de dados sob revisão. Os registos operacionais ficam no Supabase e não são recriados por builds.
