# Fotos de inspeção para anúncios

Cria aqui uma pasta com o ID do produto do dashboard e coloca uma cópia das fotografias reais dessa unidade. Junta um `produto.txt` com o nome e o ID do produto. Instruções e checklist: [Guia de inspeção e fotografias](../../docs/guia-inspecao-e-fotos.md).

Os ficheiros de imagem são ignorados pelo Git; não serão incluídos em commits nem publicados no site.
